Three months ago I wrote about [AgentDeck](/en/2026/06/17/agentdeck/): a local-first dashboard that reads the files your CLIs already write to disk, never sends anything anywhere, and shows you what Claude Code and Codex are actually doing.

I've used it every day since, and the rough edges got obvious. One provider per screen stops scaling at three or four projects. Finding last week's conversation took too many clicks. And when a CLI vendor quietly changed its on-disk format, I found out days later from a broken screen. So 2.0 is close to a rewrite. Nine things:

![tour](https://static.jimmyblog.site/2026-09-08-agentdeck-2/tour.gif)

(The video and a one-page overview live at [jimmyblog.site/AgentDeck](https://jimmyblog.site/AgentDeck/).)

## 1. A third provider: Google Antigravity

`agy` joins, with the same screens as Claude Code and Codex: Conversation, Sub-agents, Raw, Stats, Artifacts, Config. Its format is unpublished — the transcript is `transcript_full.jsonl`, and workspace, model and tokens sit in protobuf blobs inside SQLite — so I mapped the fields one by one against its own `/usage` output. Adding a provider now costs one directory under `server/providers/` and one YAML descriptor.

![antigravity](https://static.jimmyblog.site/2026-09-08-agentdeck-2/session-antigravity.webp)

## 2. Browse like a browser

A Chrome-style tab strip across providers *and* tracked folders. Every session is a tab with a deep link; tabs persist, reorder, and remember their view. Switching between three agents and a dozen projects feels like switching web pages.

![home](https://static.jimmyblog.site/2026-09-08-agentdeck-2/home-activity.webp)

## 3. Workspaces and pins

One sidebar for everything: colour-coded folder chips, **workspaces** that group the same repo from several providers and folders (suggested automatically when a folder shows up in more than one place), and **pins** for what you're on right now. Pinning or grouping *moves* a row, so nothing is listed twice.

![sidebar](https://static.jimmyblog.site/2026-09-08-agentdeck-2/sidebar-workspaces-pinned.webp)

## 4. Midnight

A new cool-slate theme next to Graphite (the default) and Paper. Themes are token overrides, so provider and workspace accents keep the right lightness in each.

## 5. Preferences

Theme, density, provider and status colours (any hex, hue/saturation sliders, your own swatches), how deep project paths display, how long Home's lists are, which sidebar sections show. Each group has an (i) with one sentence — no walls of text.

![preferences](https://static.jimmyblog.site/2026-09-08-agentdeck-2/preferences-open.webp)

## 6. Shortcuts and a quick switcher

⌘/Ctrl+K fuzzy-jumps to any project or session in any provider or folder; → browses a project's sessions by title and first prompt; Enter opens, ⌘/Ctrl+Enter opens a new tab. Alt+T / W / [ ] / 1…9 drive the tabs. The full list sits behind the ? in the tab strip, with the modifier named for your OS.

![switcher](https://static.jimmyblog.site/2026-09-08-agentdeck-2/quick-switcher-open.webp)

## 7. Insights

This page is about how *you* work with agents, not what they cost: active days in the last 30, streaks, hour-of-day and weekday rhythm, session length, prompts per session, and the projects that have gone quiet. Tokens and tool counts stay in Stats.

![insights](https://static.jimmyblog.site/2026-09-08-agentdeck-2/insights.webp)

## 8. AI features

**Ask the agent**: from any Config view (or Insights), say what you want in your own words. AgentDeck opens that provider's own terminal with a brief: your request, the file and its current content, the official docs for that kind of setting, and the CLI's building blocks (instructions, commands, rules, output styles, workflows, skills, sub-agents, hooks, MCP servers, plugins). The brief tells the CLI to **interview you first** — explain each block, one question at a time, search the skills ecosystem with the bundled find-skills, show a plan — and only then edit. AgentDeck itself never calls a model or edits a file.

![handoff](https://static.jimmyblog.site/2026-09-08-agentdeck-2/config-handoff.webp)

## 9. A provider protocol, with drift detection

The one I wanted most. Every CLI writes its own format under `~/.claude`, `~/.codex`, `~/.gemini`, and there is no shared spec. AgentDeck's `spec/` defines the contract every provider implements — one vocabulary for sessions, sub-agents (`children[]`), tool calls, tokens, memory, MCP servers, history and stats — plus a YAML descriptor per CLI and a conformance gate (fixtures with golden outputs).

Then the **format probe**: on every start it reads each tracked folder's newest records and compares them with the descriptor. A new record type, a missing required field or a changed type puts a badge on that folder's chip the same day, with details in the Folders dialog. This week it caught record types that Claude Code 2.1.263 and codex 0.153 had just added.

![folders](https://static.jimmyblog.site/2026-09-08-agentdeck-2/folders-dialog.webp)

## Also

One Stats view for all three providers (shared fields first, provider-specific ones marked); `make all` updates all three CLIs first; every demo asset comes from a synthetic data root, so no real transcript is in the repo; CI runs tests, build, the spec gate and a privacy scan on ubuntu, windows and macos.

Same ask as last time: if you work with AI coding agents every day, come try it, star it, or add a provider against `spec/` and send a PR.
